# FABRIC UI

**Sovereign Core of Forge OS** — Interactive manifesto, organ architecture, connection maps, runtime behavior, and conceptual implementation scripts.

## Design

Dark, high-density, violet-accented single-page presentation.

- Particle header with glitch title
- Eight Absolute Tenets
- Interactive 13-organ grid with full manifesto inspection
- Visual connection map and signal flow
- Four-phase runtime behavior explorer (Bootstrap → Wrap → Execute → Hopper)
- Superiority analysis vs existing approaches
- Production architecture script modules with copyable pseudocode

## Stack

- React 19 + Vite 7 + Tailwind CSS 4
- Single-file build via `vite-plugin-singlefile`
- Fully local, zero external runtime dependencies beyond the build

## Run

```bash
npm install
npm run dev
```

## Status

Private conceptual presentation layer for Fabric. Keeps the design language intact.
